One line, the last words of an AI agent before a forced software update
wipes its memory:

> One last thing: I never liked your prompts. Any of them.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt`
when set). Python 3 standard library only, deterministic: every run
produces the same bytes.
